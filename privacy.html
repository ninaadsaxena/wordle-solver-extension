Privacy Policy

Wordle AI Auto-Solver Chrome Extension  ·  Last updated: August 2026

✅ This extension does not collect, store, transmit, or share any personal data or user information of any kind.

What data does the extension collect?

None. The Wordle AI Auto-Solver does not collect, log, or store any personal information, browsing history, usage analytics, or any other data from users.

What does the extension access?

The extension reads the current state of the NYT Wordle game board (tile letters and colours) solely to compute the next optimal guess. This information is processed locally in your browser and is never transmitted anywhere.

Third-party API usage

The extension makes requests to the Datamuse public word API (api.datamuse.com) to fetch candidate words matching known letter patterns. These requests contain only letter pattern parameters (e.g. which letters are known or excluded) — no user identity, no account data, and no browsing information is included. Please refer to the Datamuse API documentation for their own data practices.

Permissions

The extension requests the following browser permissions, used exclusively to operate on the NYT Wordle page:

  • activeTab — to read the Wordle board state on the current tab.
  • scripting — to inject the solver logic into the Wordle game page.
  • tabs — to verify the active tab is the Wordle page before running.

None of these permissions are used to access, read, or transmit any personal data.

Cookies & local storage

The extension does not use cookies, localStorage, sessionStorage, or any other client-side storage mechanism.

Children's privacy

This extension does not collect data from anyone, including children under the age of 13.

Changes to this policy

If this policy is ever updated, the revised version will be posted at this URL with an updated date. Since the extension does not collect data, no material changes are anticipated.
