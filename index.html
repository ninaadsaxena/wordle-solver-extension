How to Install in 30 Seconds

Works on Chrome, Edge, Brave, Opera — any Chromium browser.

01

Download & Extract

Click the download button above to get the .zip file, then right-click it and select Extract All. Keep the extracted folder somewhere safe — the browser reads from it.

02

Enable Developer Mode

Open your browser's extensions page (chrome://extensions or edge://extensions) and toggle Developer mode ON in the top-right corner.

03

Load Unpacked & Pin It

Click Load unpacked, select the extracted extension folder, then click the puzzle-piece icon in your browser bar and pin the extension.

💡
Microsoft Edge tip: Once installed, you can turn Developer Mode back off — the extension keeps running on Edge without needing it permanently on. Chrome requires it to stay on for unpacked extensions.
📁
Keep the folder. The browser reads the extension files directly from the folder on your disk. Do not delete the extracted folder — but you can move it anywhere you like (e.g. Documents). Just re-select it if you ever reload the extension.

Frequently Asked Questions

Everything you need to know before and after installing.

Does it work on browsers other than Chrome?
Yes! The extension works on any Chromium-based browser — Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi, and others. The setup steps are nearly identical: go to your browser's extension page, enable Developer Mode, click Load Unpacked, and select the folder.
Do I need to keep Developer Mode turned on after installing?
Chrome: Yes — Chrome disables unpacked extensions when Developer Mode is off. You only need to interact with it once during setup; after that, just leave it on in the background (it has no effect on day-to-day browsing).

Microsoft Edge: Once installed, you can turn Developer Mode off and the extension continues to run normally. Edge is more permissive with locally loaded extensions.
Can I delete the downloaded zip or folder after installing?
You can delete the original .zip file after extracting — you no longer need it. However, do not delete the extracted folder. Browsers load extension files directly from that folder on your disk. If the folder is moved or deleted, the extension will stop working. You can move it to a permanent location like your Documents or Desktop.
Will this slow down my browser or use a lot of memory?
Not at all. The entire extension is under 50 KB — smaller than a single webpage image. It only activates when you click the extension button on the NYT Wordle page. It has zero impact on your browser's speed, startup time, or memory usage.
Is it safe? Does it collect any data?
100% safe. The extension is fully open source — you can read every line of code on GitHub. It does not collect, store, or transmit any personal data. The only external request it makes is to the public Datamuse API to look up valid English words.
Does it work on mobile?
Browser extensions are a desktop-only feature — Chrome and Edge on Android and iOS do not support extensions. The solver only works on the desktop versions of supported browsers.
What happens if Wordle rejects a guessed word?
The solver detects when Wordle shakes a row (indicating the word isn't in its dictionary), automatically clears the row with Backspace presses, marks that word as invalid, and picks the next best candidate from remaining candidates.
Can I use it mid-game if I've already made some guesses?
Yes! The extension reads the existing tile colours on the board when it starts. If you've already made 1 or 2 guesses, it will pick up from where you left off and continue solving from that point.
Does it work on Wordle variants like Quordle or Dordle?
Currently the extension is designed specifically for the official NYT Wordle (nytimes.com). Other variants use different page structures and are not supported at this time.
