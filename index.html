How to Install in 30 Seconds

No Chrome Web Store fees or registration required.

01

Download & Extract

Click the download button above to get the extension `.zip` file and extract it on your computer.

02

Enable Developer Mode

Open Chrome, navigate to chrome://extensions, and toggle Developer mode ON in top-right.

03

Load Unpacked

Click Load unpacked in the top-left and select the extracted extension folder.
