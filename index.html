Frequently Asked Questions

Everything you need to know before and after installing.

Does it work on browsers other than Chrome?
Yes! Since it's a standard Chrome Web Store extension, it works on any Chromium-based browser — Google Chrome, Microsoft Edge, Brave, Opera, Vivaldi. Just visit the Chrome Web Store link and click Add to Chrome. No extra setup needed on any of them.
Do I need Developer Mode or any technical setup?
No. Installing from the Chrome Web Store is identical to installing any standard extension — no Developer Mode, no ZIP downloads, and no folder management required. Chrome handles installation and updates automatically.
How does it handle popups, banners, or NYT login modals?
The solver automatically detects and dismisses cookie consent banners, privacy popups, NYT account login prompts, and side navigation menus before and during gameplay so solving is never interrupted.
How does it handle repeated letters and letter traps?
The engine uses a two-pass algorithm for exact repeated-letter feedback, and when multiple candidates share similar patterns (like _IGHT or _OUND), it evaluates high-frequency probe words to test multiple letters in a single guess.
Will this slow down my browser or use a lot of memory?
Not at all. The entire extension is under 50 KB — smaller than a single webpage image. It only activates when you click the extension button on the NYT Wordle page. It has zero impact on your browser's speed, startup time, or memory usage.
Is it safe? Does it collect any data?
100% safe. The extension is fully open source — you can read every line of code on GitHub. It does not collect, store, or transmit any personal data. Check out our transparent Privacy Policy.
Does it work on mobile?
Browser extensions are a desktop-only feature — Chrome and Edge on Android and iOS do not support extensions. The solver works on desktop versions of all Chromium browsers.
What happens if Wordle rejects a guessed word?
The solver detects when Wordle shakes a row (indicating the word isn't in its dictionary), automatically clears the row with Backspace presses, marks that word as invalid, and picks the next best candidate.
Can I use it mid-game if I've already made some guesses?
Yes! The extension reads existing tile colours on the board when it starts. If you've already made 1 or 2 guesses, it will pick up from where you left off and continue solving from that point.
Does it work on Wordle variants like Quordle or Dordle?
Currently the extension is designed specifically for the official NYT Wordle (nytimes.com). Other variants use different page structures and are not supported at this time.
